# Artwork assets

This folder contains the original, scalable cover artwork for **Cruor × Sable Compat**.

## Cover

- `cover.svg` — 1920 × 1080, vector artwork, suitable for the repository README, project pages, and graphics editors.

## Use in the main README

```markdown
![Cruor × Sable Compat](assets/cover.svg)
```

The artwork is independently created for this compatibility addon. It does not contain the original logos, models, textures, screenshots, or other copied assets from Cruor or Sable. The names are used only to identify the compatibility project.

The original artwork is covered by this repository's MIT license. The separate Cruor and Sable mods retain their own licenses.
